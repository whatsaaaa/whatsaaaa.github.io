Whatsaaaa's design system: brand identity, design tokens, typography, a docs theme and an asset kit, published on npm as `@whatsaaaa/design-system`. This site is built on it.

## What is in it

- **Identity.** The ghost in every cut, the wordmark, six poses, a sprite per project, favicons, README headers and social cards. All generated.
- **Tokens.** Rosé Pine main for dark and Dawn for light, mapped to roles, with type, space, radii and motion.
- **Styles.** Prose, code blocks, tables, lists, callouts, and the terminal frame: tab bar, prompts, status line.
- **The ghost as an element.** `<ws-ghost>`, with the easter egg.
- **Docs theme.** A VitePress theme on top of VitePress's default theme.
